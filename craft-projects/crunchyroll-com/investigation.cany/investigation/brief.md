# Brief

**Question:** Build an original-branded anime streaming-style web app (home with hero carousel and rows, genre browse, search, series page with seasons/episodes, browser-saved watchlist, YouTube trailer player) modelled on the browsing experience of crunchyroll.com.

**Purpose:** A non-coder wants a working look-alike browsing experience with a sample catalog of real titles (metadata only) and official trailers via YouTube embeds.

**Targets:**
- https://www.crunchyroll.com/

**Constraints:**
- Clean room: do not open or fetch the original site or its code
- Original name, logo and accent colour; no Crunchyroll trademarks
- Never link to or stream unlicensed episodes; trailers only via YouTube embeds
- Static build output in app/dist; change files only in app/

**Done when:** npm run build succeeds and the static site provides all six requested pages working at phone, tablet and desktop widths without sideways scroll.
