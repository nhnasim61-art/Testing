## Files

- `screenshot-1440.png` — 1440×12000 px screenshot (cut at the height limit)
- `noise-1440.png` — the parts that changed by themselves between two photos a moment apart (white, one pixel per 16 px square): carousels, videos, animations. They aren't compared.
- `screenshot-768.png` — 768×12000 px screenshot (cut at the height limit)
- `noise-768.png` — the parts that changed by themselves between two photos a moment apart (white, one pixel per 16 px square): carousels, videos, animations. They aren't compared.
- `screenshot-390.png` — 390×12000 px screenshot (cut at the height limit)
- `capture.json` — design tokens, the layout at each width (`layouts`), layout outline (positions in CSS px), headings, links, forms, picture sizes and visible text

Clean room: only what a visitor sees was kept. The page's HTML, CSS rules, scripts, requests and errors weren't read.
